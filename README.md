## Current Projects
- **[SKE-Schema](https://github.com/MunyinSam/SKEma)** - a platform for SKE students to share files and homework discussions.
- **[Discord-Music-Bot](https://github.com/MunyinSam/bot)** - a music discord bot that is easy to setup
- **[fence-vscode](https://github.com/MunyinSam/fence-vscode)** - a VS Code extension that forces comprehension before AI-generated code lands in your file, so you learn instead of vibe-coding.
- **[Chithara](https://github.com/MunyinSam/Chithara)** - a website that generates AI songs based on your vibes.
- **Sin** - a Claude Code skill repo that gates AI code generation on demonstrated understanding, reading an Obsidian vault to check what you actually know before it writes anything. *(in design)*
- **MorGraph** - a persistent knowledge-graph memory layer on top of an LLM, built for med students to chat with AI grounded in their own notes. *(in design)*
